# Missão Marte — Automação de Testes ECLSS

Projeto acadêmico de automação de testes em Python para validar
o sistema de suporte à vida de um habitat em Marte.

## Objetivos

- Validar o consumo de oxigênio e água.
- Verificar situações de estoque insuficiente.
- Testar níveis de emergência e racionamento.
- Simular a telemetria com mocks.
- Executar cenários BDD com pytest-bdd.
- Automatizar testes de navegador com Selenium.
- Executar testes e cobertura pelo GitHub Actions.

## Tecnologias

- Python 3.12
- Pytest
- Pytest-BDD
- Pytest-Cov
- Pytest-Mock
- Selenium
- GitHub Actions
